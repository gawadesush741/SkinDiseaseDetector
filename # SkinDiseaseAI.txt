# SkinDiseaseAI

## AI-Based Skin Lesion Classification Prototype

SkinDiseaseAI is a final-year project prototype that uses **Digital Image Processing (DIP), Computer Vision, Deep Learning, FastAPI, HTML/CSS/JavaScript, and MongoDB** to analyze skin-lesion images.

The system:

1. Accepts a skin-lesion image.
2. Preprocesses the image.
3. Uses a trained **ResNet18** deep-learning model.
4. Predicts one of seven lesion categories.
5. Gets additional information from MongoDB.
6. Displays the prediction, model confidence, description, causes/associations, general care, and medical-attention guidance.

> **Important:** This is an educational/research prototype and is **not a medical diagnostic system**. AI predictions can be incorrect. Concerning, changing, bleeding, painful, or persistent skin lesions should be evaluated by a qualified healthcare professional.

# 22. Important: Understanding Confidence

The value:

```text
confidence: 90.98
```

means the model assigned approximately 90.98% probability to its predicted class among the seven classes.

It does **not** mean:

```text
90.98% medical accuracy
```

and it does not mean that the user has a 90.98% chance of having that disease.

The application should therefore present this as:

```text
Model Confidence
```

rather than:

```text Medical Certainty
```

---

# 23. Important Dataset Limitation

The training dataset primarily contains **dermatoscopic skin-lesion images**.

Therefore, this prototype should not be described as a system capable of detecting every type of skin disease from any ordinary mobile-phone photograph.

For a final-year project, a suitable description is:

> "An AI-based skin lesion classification prototype using dermatoscopic image data."

Future versions could use additional datasets containing clinical/mobile-phone images.

---

# 24. Medical Safety

This application is an educational/research prototype.

It should not be used to:

* Confirm a medical diagnosis
* Replace a dermatologist
* Decide whether medical treatment is required
* Recommend prescription medication
* Guarantee that a lesion is harmless

Users should seek professional medical evaluation for concerning lesions, particularly lesions that are:

* Changing
* Growing
* Bleeding
* Painful
* Persistent
* Itchy or irritated
* Unusual in appearance
